# Astra Test — 메이플스토리 화면 관측

Windows 11 / 메이플스토리 창모드 1366×768에 맞춘 로컬 실행 구현입니다.

## 실행

PowerShell에서:

```powershell
cd C:\Coding\astra_test
.\run.ps1
```

창에서 소리 알림 여부를 선택한 뒤 **감시 시작**을 누릅니다. 소리 설정은 시작 시 적용됩니다. 게임을 종료하거나 최소화하면 관측값은 알 수 없음으로 전환됩니다. 종료 후 게임을 다시 실행한 경우 감시를 중지하고 다시 시작하세요.

새 환경 설치: `powershell -ExecutionPolicy Bypass -File .\setup.ps1` (Python 3.10 이상 필요). 최초 OCR 모델 초기화에는 네트워크가 필요할 수 있습니다.

```powershell
# 소리 없이 제한 시간 관측
.\.venv\Scripts\python.exe -X utf8 -m astra_test.app --headless --seconds 15
# 회귀 검사
.\.venv\Scripts\python.exe -X utf8 -m pytest -q
# 루트 PNG 표본의 재현 가능한 분석 보고서
.\.venv\Scripts\python.exe -X utf8 -m astra_test.review --output work\review
```

## 구현

- **캡처:** 게임 HWND를 지정하는 Windows Graphics Capture. 다른 창에 가려진 게임을 캡처합니다. DLL 주입이나 게임 입력은 사용하지 않습니다. 최소화 상태의 정상 렌더링은 보장되지 않으며 오래된 프레임으로 판정하지 않습니다.
- **경험치:** 하단 HUD에서 정확한 정수와 퍼센트 문법을 검사합니다. 연속 유효 관측에서 7,000ms 증가가 없을 때 알림. OCR 실패/프레임 간격 500ms 초과/경험치 감소는 다시 기준을 잡습니다.
- **버프:** 윤곽 + 승인 템플릿 + 우측 정렬 32px 격자. 이름과 숫자 의미를 구분하며, B03의 스택을 시간으로 쓰지 않습니다. 이름 미확인 아이콘도 위치별로 나열합니다.
- **비약:** 사용자 확인 P04. 10분 이상 흰 숫자는 분 단위, 노란 m:ss는 초 단위 OCR. 분 표시를 임의의 초 단위 정답으로 바꾸지 않습니다.
- **부스터:** 중앙 상단 고정 라벨을 찾고 초 숫자를 읽습니다. 0~100초 범위와 OCR 문법을 검사합니다.
- **룬:** 탐지된 미니맵 안에서 승인된 분홍색 마름모 템플릿과 색상 조건을 함께 검사합니다.
- **거짓말 탐지기:** 제공한 4종 이미지, 이동형 영상의 고정 안내 영역, 비올레타 고정 버튼 프레임의 SIFT 특징 및 한국어 고정 안내문 OCR. 정답을 판독·선택하거나 클릭하지 않습니다.
- **알림:** 경험치 정체, 룬 등장, 거짓말 탐지기 등장, 비약 종료, 부스터 종료. 등장 알림은 2회 확인. 종료는 마지막 5초 이내의 유효 카운트다운을 본 후 0 또는 예상 종료 직후 소멸을 관측한 경우에만 추정합니다. 조기 해제/마지막 초를 놓친 경우 종료를 확정하지 않습니다.

경험치, 비약·부스터·룬, 전체 버프 목록, 탐지기는 별도 작업 스레드로 실행합니다. 우선 타이머는 가능한 경우 0.5초 간격, 전체 버프 목록은 최소 2초 간격, 탐지기는 최소 1초 간격이며 실제 처리 속도에 따라 늦어질 수 있습니다. 남은 시간의 **표시 해상도**와 **갱신 지연**은 다릅니다. `work/latest.json`에서 HUD/탐지기 자료의 나이 및 처리 시간을 확인할 수 있습니다.

`work/events.jsonl`: 알림 기록, `work/session.json`: 제한 관측 요약. CAPTCHA 정답 OCR 텍스트는 기록하지 않습니다. CLI 검증은 마지막 게임 화면을 `work/latest_client.png`에 저장합니다.

## 검증 범위와 남은 보정

사용자 제공 게임 전체 화면 5장, 버프 행 1장, 미니맵 1장을 분석했습니다. 비약은 29분 / 14분 / 9:21 / 9:07 / 8:51, 부스터는 양성 표본에서 69.00초를 읽었습니다. 실게임 창 재탐지 및 WGC 관측도 수행했습니다.

이 표본들은 등록/보정에도 사용한 **회귀 표본**입니다. 실전 정확도나 거짓말 탐지기 무누락을 증명하는 독립 평가가 아닙니다. 새로운 UI 크기, 노이즈, 아이콘 명암, 지도에서 추가 검증이 필요합니다. 미확인 숫자는 스택일 수 있어 사용자 확인 전에는 시간으로 단정하지 않습니다. 현재 버프 개수는 격자에 기반한 후보 수입니다.

구현 GUI는 Tkinter, OCR은 RapidOCR/ONNX Runtime, 영상 처리는 OpenCV입니다. 초기 설계 문서의 PySide6 및 학습 모델 계획은 장기 계획이며 현재 구현과 다릅니다. 실제 동작은 `src/astra_test/`와 `config/labels.json`을 기준으로 합니다. `config/design.defaults.json`은 초기 설계 자료이며 런타임 설정 파일이 아닙니다.


추가 확인: U02·U05~U08·U10~U12는 초, U00·U01·U13·U15~U17은 분:초, U14는 분입니다. 이름은 아직 미확인입니다. 버프가 35개인 제공 화면에서 이 단위와 값을 회귀 검증했습니다. 비약 1분 미만은 확인된 57초 글리프를 합성한 전환 테스트를 추가했으며 실제 비약 표본 검증은 남아 있습니다.

게임 안의 툴팁은 WGC에도 포함됩니다. 큰 어두운 툴팁이 버프를 가리면 개수와 비약 종료 판정을 알 수 없음으로 처리합니다. 이 가림 판정도 휴리스틱입니다. 거짓말 탐지기 특징 검사는 전체 프레임에, 안내문 OCR 보조 검사는 중앙 영역에 적용합니다. 검사 시간이 길거나 표본과 다른 화면에서는 감지가 늦거나 누락될 수 있습니다.
